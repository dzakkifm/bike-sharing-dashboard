# Bike Sharing Data Analytics Dashboard 🚲

## Description
Dashboard interaktif ini dibuat untuk menganalisis tren penyewaan sepeda berdasarkan kondisi cuaca serta pola penggunaan per jam antara pengguna casual dan registered selama tahun 2012.

## Setup Environment - Anaconda / Terminal

```bash
conda create --name main-ds python=3.12
conda activate main-ds
pip install -r requirements.txt
```

## Run Streamlit App
```bash
streamlit run dashboard/dashboard.py
```
